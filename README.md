## 🎯 Learning Objectives

- Understand the fundamentals of data visualization.
- Learn the working principles of various information visualization tools.
- Acquire knowledge of the issues involved in data representation.
- Visualize data hands-on using **Tableau**.

**Course Description:** This course introduces the basic concepts of data analytics for understanding the importance of collecting, validating, managing, and presenting data. It lays strong foundations on tools and techniques for data management and visualization, and integrates them with allied management disciplines.

## 📚 Curriculum

### Unit I — Foundations of Data Visualization
Context of data visualization — definition, methodology, visualization design objectives · Key factors — purpose, visualization function and tone, design options · Data representation and data presentation · Seven stages of data visualization · Widgets and data visualization tools · Introduction to mapping, time series, connections and correlations, scatterplot maps, trees, hierarchies, recursion, networks and graphs.

### Unit II — Mapping, Hierarchies & Network Visualization
Time series, connections and correlations · Indicator-area charts, pivot tables, scatter charts, scatter maps · Tree maps — space-filling and non-space-filling methods · Hierarchies and recursion · Networks and graphs — displaying arbitrary graphs, node-link graphs, matrix representation for graphs · Infographics.

### Unit III — Acquiring & Parsing Data
Where to find data · Tools for acquiring data from the internet · Locating and loading files, dealing with files and folders, listing files in a folder · Asynchronous image downloads · Web techniques · Parsing data — levels of effort, tools for gathering clues, text markup languages, regular expressions, grammars and BNF notation · Compressed data, vectors and geometry, binary data formats · Advanced detective work.

### Unit IV — Drawing, Interactivity & Secure Visualization
Drawing with data — scales, axes, updates, transitions and motion, interactivity, layouts · Port scan visualization · Vulnerability assessment and exploitation · Firewall log visualization · Intrusion detection log visualization · Attacking and defending visualization systems · Creating secured visualization systems.
